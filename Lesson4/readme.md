## Azure Cognitive Services

Данный раздел был переименован в `Azure Ai Services`. Тут вы можете найти практически любое готовое решение для вашего приложения. Начиная от поисковика, заканчивая распознаванием речи и изображений. Ко всему этому добавляюся GPT которые вы можете обучить сами. Одним из самых полезных сервисов по моему мнению является Chat Bot для вашего сайта. Эту функию мы тоже посмотрим.
