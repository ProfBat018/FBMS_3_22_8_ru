## Создание 4 частей для микросервиса

Я думаю что в нашем случае проект не должен нести никакой смысловой нагрузки, поэтому я решил создать 4 простых, можно сказать что пустых части для микросервиса.

1. **Api Gateway** - это входная точка для всех запросов, он будет принимать запросы и перенаправлять их на нужные микросервисы. Его мы напишем на Ocelot.

2. **Auth Service** - сервис который будет отвечать за авторизацию пользователей. В нашем случае он будет принимать запросы на авторизацию и возвращать токен.

3. **Movie Service** - сервис который будет отвечать за работу с фильмами. В нашем случае он будет принимать запросы на получение списка фильмов и возвращать их.

4. **React app** - это наш клиент, который будет общаться с Api Gateway и получать данные от Movie Service.

Микросервисная архитектура предпологает что у каждого вашего сервиса будет своя БД, конечно не всегда это получается, но мы это сделаем.
