# Тема урока: Тестирование и отладка реакт приложений 


## Отладка

Мне не стоит объяснять, что такое отладка. Если говорить коротко, то есть несколько способов отладки в React:
- React DevTools extension
- Visual Studio Code debugger

Делать отладку в VS Code нежелательно обычным способом. Я все же советую делать отладку в браузере, используя React DevTools extension. 


## Тестирование

Тестирование в React - это важная часть разработки. В React есть несколько библиотек для тестирования:
- Cypress
- Jest
- Playwright


### Cypress

Cypress - это инструмент для тестирования веб-приложений. Он позволяет писать тесты на JavaScript и TypeScript. Cypress позволяет писать тесты, которые будут работать в браузере.

Для начала работы с Cypress, нужно установить его. Для этого нужно выполнить команду:

```bash
npm install cypress --save-dev
```

Тут --save-dev означает, что пакет будет установлен как devDependency и не будет включен в production сборку.

После установки Cypress, нужно создать файл cypress.json в корне проекта. В этом файле нужно добавить следующий код:

```json
{
  "baseUrl": "http://localhost:3000"
}
```

Тут baseUrl - это адрес, на котором запущено приложение.

После этого нужно добавить скрипт в package.json:

```json
{
  "scripts": {
    "cypress:open": "cypress open"
  }
}
```

Теперь можно запустить Cypress:

```bash
npm run cypress:open
```

После этого откроется окно Cypress, в котором можно писать тесты.
