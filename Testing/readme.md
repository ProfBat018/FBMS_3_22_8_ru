# Testing в C# 


Есть два вида тестирования:
1. **Модульное тестирование** - тестирование отдельных модулей программы.
2. **Интеграционное тестирование** - тестирование взаимодействия между модулями.

## Модульное тестирование

Unit-тестирование - это тестирование отдельных модулей программы. В C# для этого используется библиотека `NUnit`. Также есть библиотеки `xUnit` и `MSTest`.

Разница между ними в том, что `NUnit` и `xUnit` - это open-source библиотеки, а `MSTest` - это библиотека от Microsoft. По идее просто разные атрибуты и методы, но в целом они делают одно и то же. 

Мы будем использовать `NUnit`.
