## Что такое NEST.JS ?

`NEST.JS` - это фреймворк для создания серверных приложений на `Node.js`. Он предоставляет нам множество инструментов для создания масштабируемых и эффективных приложений. Он построен на основе `Express.js` и предоставляет нам множество дополнительных возможностей, таких как внедрение зависимостей, модульность, тестирование и многое другое.

## Плюсы и минусы использования NEST.JS

### Плюсы:

- Модульность
- Внедрение зависимостей
- Встроенная поддержка тестирования
- Встроенная поддержка микросервисов
- Встроенная поддержка графовых запросов

### Минусы:

- Сложность изучения
- Сложность внедрения в существующий проект

## Как создать проект на NEST.JS с typescript

Для начала нам нужно установить `NEST.JS CLI`:

```bash
npm i -g @nestjs/cli
```

Теперь создадим новый проект:

```bash
nest new project-name
```

После этого нам нужно установить `TypeScript`:

```bash
npm i -D typescript
```

И создать файл `tsconfig.json`:

```json
{
  "compilerOptions": {
    "module": "commonjs",
    "declaration": true,
    "removeComments": true,
    "emitDecoratorMetadata": true,
    "experimentalDecorators": true,
    "target": "es6",
    "sourceMap": true,
    "outDir": "./dist",
    "baseUrl": "./",
    "incremental": true,
    "paths": {
      "*": ["node_modules/*"]
    }
  }
}
```

Теперь мы можем запустить наше приложение:

```bash
npm run start
```
