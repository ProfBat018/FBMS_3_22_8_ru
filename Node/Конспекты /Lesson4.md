# Что такое MongoDB

`MongoDb` - это документо-ориентированная база данных, которая хранит данные в формате BSON. Это документо-ориентированная база данных, что означает, что данные хранятся в документах, а не в таблицах. Каждый документ представляет собой набор пар ключ-значение. Каждый документ хранится в коллекции, а коллекции хранятся в базе данных.

Если сравнить его с `MsSql`, то можно прийти к следующим выводам:

- коллекция - это таблица
- документ - это строка

# Подключения MongoDb к Express.js

Для подключения к базе данных `MongoDb` из `Express.js` используется библиотека `mongoose`. Для начала установим ее:

```bash
npm install mongoose
```

# MongoDb Atlas & Compass

Для работы с базой данных `MongoDb` можно использовать `MongoDb Atlas` - облачный сервис, который предоставляет возможность создания баз данных `MongoDb` в облаке. Там вы можете бесплатно создать для себя базу данных и без проблем с ним работать. Также можно использовать `MongoDb Compass` - графический интерфейс для работы с базой данных `MongoDb`.
В свою очередь `Compass` позволяет вам сделать так, чтобы вы подключили все на локальной машине, а не в облаке.
