# Типы сетей в Docker: Bridge, Host, None

Docker предоставляет несколько типов сетей для контейнеров, каждый из которых имеет свои особенности. Ниже рассмотрены основные отличия между Bridge, Host и None сетями.

## 1. **Bridge Network (Мостовая сеть)**

### Описание
- **Bridge** — это стандартный тип сети, создаваемый Docker по умолчанию.
- Контейнеры, подключенные к одной мостовой сети, могут взаимодействовать друг с другом.
- Внешние устройства подключаются к контейнерам через NAT (Network Address Translation).

### Преимущества
- Хорошо изолирует контейнеры от хоста и других сетей.
- Простота настройки.
- Подходит для сценариев, где контейнеры должны взаимодействовать между собой, но ограничивать доступ извне.

### Особенности
- Docker присваивает контейнерам IP-адреса из диапазона этой сети.
- Вы можете настроить свои bridge-сети, используя команду `docker network create`.
