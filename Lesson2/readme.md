## Resource groups

Группы ресурсов - это способ организации и управления ресурсами в Azure.

По факту они не имеют никакой смысловой нагрузки. Только организация ресурсов. Конечно же вы можете подумать что их не будет так много, вот пример того что создается автомматически при создании одной виртуальной машины для `Deploy`.

![](./Screenshot%202024-11-04%20at%2019.15.44.png)

Вы можете представить себе что это обычная книжная полка или же сумка. Его смысл чтобы ресурсы разных проектов не смешивались друг с другом и не путали вас.

## Availability options

- No infrastructure
- Availability zone
- VM scale set
- Availability set

`Первый вариант` никак не копирует наши данные на другой диск или сервер. Проще говоря при пожаре ваши данные просто сгорят

`Второй вариант` копирует ваши данные на другой ближайжий сервер в этом же регионе

`Третий вариант` Делает тоже самое что и второй но в разных регионах, при этом копируя не только данные но и весь сервер.

`Четвертый вариант` Делает автоматически все что нужно чтобы ваши данные не потерялись.
