# JavaScript vs TypeScript

И тот и другой - это языки стандарта ES6

ES6 - это стандарт ECMAScript, который был выпущен в 2015 году.

Можно задать вопрос, смысл использования TypeScript, если JavaScript уже существует ?

Ребята в компании Microsoft поняли, что будет очень полезно добавить ООП фишки, которые есть в C# и Java в JavaScript. И они создали TypeScript. К тому же при эволюции JS, были добавлены функции, которые не всегда удобны в использовании. TypeScript позволяет использовать эти функции, но при этом писать код в стиле ООП.

TypeScript - это надстройка над JavaScript, которая добавляет типизацию и ООП фичи.

## Javascript and TypeScript interoperability

Это значит что, TypeScript код может быть использован в JavaScript, но не наоборот. TypeScript код компилируется в JavaScript код.


Вы даже можете использовать JavaScript библиотеки в TypeScript коде.

## Конфигурация TypeScript

Для начала работы с TypeScript, нужно установить его. Для этого вам нужно установить Node.js и npm.

После установки Node.js и npm, вы можете установить TypeScript с помощью npm.

```bash
npm install -g typescript
```

После установки TypeScript, вы можете создать файл с расширением .ts и скомпилировать его в .js файл.


### tsconfig.json

Этот файл содержит настройки компилятора TypeScript. Вы можете создать его вручную или с помощью команды:

```bash

tsc --init

```

## TypeScript Data Types 

TypeScript поддерживает все типы данных, которые есть в JavaScript. Но TypeScript также поддерживает типы данных, которых нет в JavaScript. Вот список типов данных, которые поддерживаются TypeScript:

![Типы данных](./assets/Screenshot%202024-05-16%20at%2011.34.10.png)


Показываю типы данных, которые мы не знаем. 

#### Tuple

Тоже самое что и в Python, это массив, который содержит элементы разных типов.

#### Any

Этот тип данных можно использовать, когда вы не знаете тип данных переменной. Например, когда вы получаете данные из API. 

#### Void

Этот тип данных используется, когда функция ничего не возвращает.

Также его используют, когда переменная не имеет значения или имеет значение undefined.

#### unknown 

Этот тип данных похож на any, но с одним отличием. Вы не можете присвоить переменной тип unknown другой тип данных.

#### never

Этот тип данных используется, когда функция всегда выбрасывает ошибку или никогда не завершается. Вот пример:

```typescript

function throwError(message: string): never {
  throw new Error(message);
}

```
