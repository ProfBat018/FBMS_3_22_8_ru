# Router

Как я уже вам говорил, `react` не является полноценным фреймворком, а лишь библиотекой. Поэтому много чего в `react` написано сторонними разработчиками. Конечно же мы можем обойтись без них, но уже есть список библиотек, которые настолько хороши, что их используют в каждом проекте. Одной из таких библиотек является `react-router`.

Вот официальная документация: [https://reactrouter.com/web/guides/quick-start](https://reactrouter.com/en/6.23.1)
