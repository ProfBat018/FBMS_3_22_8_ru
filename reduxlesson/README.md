# Тема урока: React-redux 

`Redux` - это библиотека для управления состоянием приложения. Она позволяет хранить все данные в одном месте и управлять ими централизованно.

`React-redux` - это библиотека, которая позволяет использовать `Redux` в приложениях на `React`.

Так как `redux` есть еще и на `Angular`, мы сталкиваемся с таким названием `react-redux`.

`Redux` - самая популярная библиотека для управления состоянием приложения. Она позволяет хранить все данные в одном месте и управлять ими централизованно.

Для начала давайте разберемся с проблмой, которую решает `Redux`. Неужели на недостаточно `useState` и `useReducer` ?

Все началось с того, что разработчики все чаще стали передавать данные через пропсы в компоненты. Это привело к тому, что данные начали передаваться через несколько уровней вложенности. И в какой-то момент стало сложно понять, откуда приходят данные и куда они уходят.

`Redux` решает эту проблему, предлагая хранить все данные в одном месте - `store`. Все компоненты могут получать данные из `store` и обновлять их в нем. Таким образом, данные становятся централизованными и управляемыми.

`Redux` состоит из нескольких частей:
- `store` - хранилище данных
- `actions` - функции, которые описывают, что происходит в приложении
- `reducers` - функции, которые обновляют данные в `store` в зависимости от `actions`

Пользуемся мы им практически так же как и `useReducer`, только вместо `dispatch` мы используем `actions`.

Для его установки используем команду:
```bash
npm install redux react-redux
```
