# Тема урока - GitLab 

`GitLab` - это веб-сервис для хостинга проектов и управления ими с помощью системы контроля версий Git. Более того, он является платформой с открытым исходным кодом, для работы DevSecOps. `DevSecOps` - это практика, которая объединяет разработчиков, операторов и специалистов по безопасности в единую команду, которая автоматизирует процессы разработки, тестирования и развертывания программного обеспечения.
По сути это `DevOps` плюс безопасность. 

Предположим у нас есть проект на микросервисной архитектуре, который состоит из нескольких микросервисов. Мы можем залить все это на GitLab и настроить CI/CD, чтобы автоматизировать процессы сборки, тестирования и развертывания.

Давайте зальем наше микросервисное приложение на GitLab и настроим CI/CD.

Раз и навсегда объясняю, что такое CI/CD. `CI/CD` - это практика разработки программного обеспечения, которая объединяет непрерывную интеграцию (CI) и непрерывное развертывание (CD). Цель CI/CD - автоматизировать процессы сборки, тестирования и развертывания программного обеспечения.

`CI - continious integration` - это практика, при которой разработчики регулярно сливают свой код в общий репозиторий. После этого происходит автоматическая сборка и тестирование кода. Если тесты прошли успешно, то код сливается в основную ветку.
`CD - continous deployment` - это практика, при которой код автоматически разворачивается на тестовом сервере после успешного прохождения тестов. Если тесты прошли успешно, то код разворачивается на продакшене.

То есть, сперва происходит непрерывная интеграция, а затем непрерывное развертывание.
